Build Tool Setup

Blocks3D has two main build environments:
  1. Visual Studio .NET 2003
  2. Visual C++ 2005
As well as several libraries, for which you can find the setup guide here.

Visual Studio .NET 2003 is old software that can be purchased off of ebay, and copies may be floating online elsewhere.

For visual studio 2005, we use Express Edittion, that is freely available directly from Microsoft in ISO and IMG form.
They are also available on archive.org in ISO and IMG form.

Setup guides are available for both, and you can also use any IDE you prefer.

All code must be compatible with Visual Studio .NET 2003 as we use an official CD copy of this to build Blocks3D releases.
Please ensure the solution files are up to date respectively.
