Visual Studio .NET 2003 Setup

Visual Studio 2003 is fairly simple to set-up, but if you're only setting it up for Blocks3D you might want to make it ligher by only selecting useful programs.
Warning - This setup can encounter some issues. Please refer to the Common Issues section if you encounter one.

Common Issues

1. Prerequisites not met and failing to install

If you tried to install prerequisites already, and are completely unable, there's a simple workaround
This may happen on machines newer than Windows XP, or if you have already installed a newer .NET framework.

Resolution:
Ensure you have extracted the Visual Studio 2003 installation files to a known directory, rather than a temp folder.
In this instance, they are under C:\VS03.
In a command prompt, navigate to the Setup subdirectory of your installer files, in this case C:\VS03\Setup, and run the following command:
setup.exe /NO_BSLN_CHECK

This will bypass prerequisite checks, and you can continue installing Visual Studio.
